# Raw Source Samples

This folder provides small samples of the source material used to construct
SciEvo-Lineage.

The full raw PDF/Markdown working directory is not redistributed in this Git
repository. The release dataset is a structured derivative built from public
paper metadata, open abstracts, and open-access PDFs. The file
`source_metadata_samples.json` contains 10 representative source records with
Semantic Scholar IDs, arXiv/DOI links when available, abstracts or abstract
excerpts, domain labels, and the parsing route used by the pipeline.

These samples are provided for provenance inspection only. Original papers
remain copyrighted by their authors and publishers.
