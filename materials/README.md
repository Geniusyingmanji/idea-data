# Submission Materials

This folder contains optional presentation materials for the SciEvo-Lineage
submission.

| File | Description |
|---|---|
| `SciEvo-Lineage_Submission.pdf` | 10-page Chinese PDF presentation for reviewers |
| `SciEvo-Lineage_Overview.mp4` | 70-second silent overview video generated from the same slides |
| `SciEvo-Lineage_Overview_Script.md` | Narration script for live presentation or voice-over |

The video includes a silent AAC audio track for platform compatibility.
